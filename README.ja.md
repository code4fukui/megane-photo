# megane-photo

顔のランドマーク検出を利用して、画像内の顔にApple Vision Pro風のメガネを自動的に合成（オーバーレイ）するWebアプリケーションです。

## デモ

**ブラウザで試す: [https://code4fukui.github.io/megane-photo/](https://code4fukui.github.io/megane-photo/)**

ページを開くと、効果を確認するためのサンプル画像が読み込まれます。その後、自分の画像をキャンバスにドラッグ＆ドロップして試すことができます。

## 機能

-   **シンプルなインターフェース:** 画像ファイルをドラッグ＆ドロップするだけで利用できます。
-   **自動顔検出:** 1枚の画像から最大10人までの顔を識別して処理します。
-   **スマートな合成:** 検出されたそれぞれの顔にApple Vision Pro風のメガネ画像を配置します。
-   **動的な調整:** 目の位置に基づいて、メガネの適切なサイズと回転角度を自動的に計算します。

## 使い方

1.  **デモリンクを開きます。** 初期状態では、すでにメガネが適用されたテスト画像が表示されます。
2.  **自分の画像ファイルをWebページ上にドラッグ＆ドロップ**します。
3.  アプリケーションが即座に顔を検出し、メガネを合成します。

## 仕組み

このプロジェクトでは、Googleの[MediaPipe Face Mesh](https://chuoling.github.io/mediapipe/solutions/face_mesh.html)ライブラリを使用し、ブラウザ上で直接、顔のランドマークの3Dメッシュを検出します。

アプリケーションは、ランドマークデータから左右の目の座標を特定します。次に、これら2点間の距離と角度を計算することで、メガネ画像の適切なスケール（拡大縮小率）と回転角度を決定し、キャンバス上に合成します。

## 動作環境

-   モダンなWebブラウザ。インストールは不要です。
